# finance_app — แอปบันทึกบัญชีรายรับ-รายจ่าย

Flutter project ที่สร้างจากโน้ตออกแบบ (flowchart หน้าจอ) ของคุณ

## โครงสร้างหน้าจอ (ตรงกับโน้ต)

- **หน้าหลัก** (`home_screen.dart`) — ปุ่มไปยัง บัญชี / รายรับ / รายจ่าย / การลงทุน / บทวิเคราะห์ / ออกจากแอป
  พร้อมรายการล่าสุด ที่ **แตะ 2 ครั้งเพื่อทำรายการซ้ำ** ตามที่ระบุในโน้ต
- **บัญชี** (`account_screen.dart`) — กด `+` เพื่อเพิ่มบัญชี, แสดงยอดคงเหลือแต่ละบัญชี
- **รายรับ / รายจ่าย** (`income_screen.dart`, `expense_screen.dart` ใช้ `transaction_form_screen.dart` ร่วมกัน)
  — เลือกบัญชี, กรอกจำนวนเงิน, เลือกหมวดหมู่ (ท่าใช้จ่ายต่างๆ), บันทึก แล้วยอดจะไปหักปรับที่บัญชี
- **พอร์ตการลงทุน** (`portfolio_screen.dart`) — กด `+` เพิ่มบัญชีลงทุน, แตะบัญชีเพื่อบันทึกกำไร/ขาดทุน,
  มีกราฟเส้นแสดงมูลค่าพอร์ต และตัวเลือกช่วงเวลา วัน/สัปดาห์/เดือน/ปี/3ปี/ทั้งหมด
- **บทวิเคราะห์** (`analysis_screen.dart`) — สรุปรายรับ/รายจ่ายตามช่วงเวลา พร้อมกราฟวงกลมแบบโดนัท
  (โปร่งใสตามที่ร่างไว้ในโน้ต) แยกตามหมวดหมู่รายจ่าย

## โครงสร้างไฟล์

```
lib/
  main.dart                        จุดเริ่มต้นแอป + ตั้งค่าธีม/ฟอนต์ไทย
  models/
    account.dart                   โมเดลบัญชี
    transaction_entry.dart         โมเดลรายการรายรับ/รายจ่าย
    investment_account.dart        โมเดลบัญชีลงทุน + รายการกำไร/ขาดทุน
  services/
    app_data.dart                  สถานะกลางของแอป (ChangeNotifier) — เก็บข้อมูลทั้งหมดและ logic คำนวณ
  screens/
    home_screen.dart
    account_screen.dart
    income_screen.dart
    expense_screen.dart
    transaction_form_screen.dart   ฟอร์มร่วมของรายรับ/รายจ่าย
    portfolio_screen.dart
    analysis_screen.dart
  widgets/
    period_selector.dart           แถบเลือกช่วงเวลา (ใช้ในหน้าลงทุน/บทวิเคราะห์)
    transaction_tile.dart          แถวรายการ (รองรับแตะ 2 ครั้งเพื่อทำซ้ำ)
```

## วิธีรัน

โปรเจกต์นี้เขียนโค้ดไว้ครบแล้ว แต่ยังไม่ได้ build/test เพราะเครื่องมือนี้ไม่มี Flutter SDK ติดตั้งอยู่
ให้ทำตามขั้นตอนนี้บนเครื่องของคุณ (ต้องติดตั้ง [Flutter SDK](https://docs.flutter.dev/get-started/install) ก่อน):

```bash
cd finance_app
flutter pub get
flutter run
```

## หมายเหตุ

- ข้อมูลตอนนี้เก็บใน memory เท่านั้น (ไม่ persist เวลาปิดแอป) — มีข้อมูลตัวอย่าง (เงินสด, บัญชีธนาคาร,
  กองทุนหุ้นไทย) ให้ทดลองใช้งานได้ทันที
- ถ้าต้องการให้บันทึกข้อมูลถาวร แนะนำเพิ่ม `sqflite` หรือ `hive` แล้วต่อยอดจาก `AppData` (services/app_data.dart)
  ซึ่งเป็นจุดเดียวที่ควบคุมข้อมูลทั้งหมดของแอป
- กราฟใช้ package `fl_chart`: กราฟวงกลมโดนัทที่หน้าบทวิเคราะห์ และกราฟเส้นที่หน้าพอร์ตการลงทุน
- ปุ่ม "ออก" ที่หน้าหลักจะมี dialog ยืนยันก่อนปิดแอป (`SystemNavigator.pop()`)
